# VESTIBULE — Card Art Direction Guide

**Size:** 64×64px minimum (renders at 58px in hand, scales up on hover)
**Style:** Dark pixel art. Think Darkest Dungeon meets doom metal album covers.
**Background:** Transparent or near-black (#0A0602). The card frame provides the border.
**Color palette:** Muted with one accent color per type:
- RIFF (purple #9933CC) — instruments, energy, power
- CORRUPT (blood red #AA1111) — skulls, demons, darkness
- UTILITY (green #22AA44) — tools, scrolls, shields
- EMBER (orange #C87820) — fire, electricity, fuel

**Drop finished PNGs at:** `public/vestibule/cards/[id].png`
No code changes needed — auto-loads on next build.
